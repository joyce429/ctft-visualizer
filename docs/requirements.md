# 需求基线

## 总体目标

基于《Signals and Systems》第二版第 4 章构建连续时间傅里叶变换交互式学习网页。最终产品应选择或输入时域信号，显示解析式并绘制时域、幅度谱和相位谱，支持典型变换性质对比；可通过 `file://` 离线打开，也可部署为纯静态网站。

## 全局数学约定

- 分析式：`X(jω)=∫_{-∞}^{∞}x(t)e^{-jωt}dt`。
- 综合式：`x(t)=(1/(2π))∫_{-∞}^{∞}X(jω)e^{jωt}dω`。
- 频率变量统一为角频率 `ω`，单位 `rad/s`。
- `sinc(z)=sin(z)/z`，并以连续延拓定义 `sinc(0)=1`。
- 狄拉克冲激保存位置与复权重；主值分布保存符号意义，均不得当作普通采样数组。

## 第一阶段范围（本次）

- 建立模块化目录和离线构建路线。
- 核查第 4.6 节变换性质与基本变换对，并记录可追溯来源。
- 建立 JSON 信号库和独立参考文献库。
- 覆盖单位冲激、平移冲激、常数、单位阶跃、矩形、三角、单边指数、双边指数、`te^{-at}u(t)`、正弦、余弦、复指数、sinc。
- 预留并实现周期矩形波、周期冲激串的数学记录与有限显示窗线谱生成。
- 实现复数、频谱类型、基础信号计算和时移/翻转/尺度/微分/积分性质。
- 真实执行自动化测试，检查公式、约束、符号、`2π` 和特殊点。
- 建立 `requirements.md`、`progress.md`、`test-report.md`。

## 明确不在第一阶段

- 完整 HTML 页面、视觉主题、响应式布局。
- Canvas/SVG/WebGL 图形与交互动画。
- 任意数学表达式解析器。
- 后台服务、用户账户、MySQL/SQLite。
- 在线 API、CDN 字体或运行时网络依赖。
- 第二阶段的可访问性与浏览器矩阵验收。

## 数据字段验收

每条信号记录至少包含：`id`、`category`、`nameZh`、`nameEn`、`timeExpressionLatex`、`frequencyExpressionLatex`、`parameters`、`defaultValues`、`constraints`、`spectrumType`、`description`、`references`。另以 `implementationId` 连接纯 JavaScript 计算实现。

## 第一阶段完成条件

- 所有 JSON 可解析，ID 唯一，引用可解析到 `references.json`。
- 15 条当前记录均存在可执行实现。
- 离线生成模块包含三套 JSON 数据。
- 测试命令无网络即可运行且全部通过。
- 文档准确区分教材原表条目与派生变换对。

## 第二阶段范围（已实现）

- 从现有数据库读取信号名称、公式、参数、限制与频谱类型。
- 以解析信号模型生成连续谱数据，不使用 FFT 替代解析公式。
- 建立浅色、蓝色系、左右分栏的教学科研软件界面。
- 提供信号分类选择、动态滑块与数值输入。
- 绘制时域、幅度谱和相位谱，支持弧度/角度切换。
- 连续谱悬停显示 `Re`、`Im`、幅值和相位。
- 冲激谱以箭头/谱线显示位置和复系数，不伪装成普通连续函数。
- 主值分布显示准确公式、奇点留空和特殊频率说明。
- 支持缩放、恢复默认视图、图例和响应式尺寸。
- 生成无需 CDN、运行时 `fetch` 或后台的 `dist/index.html`。

## 第二阶段明确不包含

- 时间翻转、平移、尺度、微分、积分的页面操作。
- 任意表达式输入。
- 变换前后双图比较与教学步骤动画。
- 在线发布或服务器端功能。

## 第三阶段范围（已实现）

- 时间翻转：`x(-t) ↔ X(-jω)`。
- 时间平移：`x(t-t0) ↔ e^{-jωt0}X(jω)`，`t0` 可正可负。
- 时间尺度：`x(at) ↔ (1/|a|)X(jω/a)`，`a` 可正可负且不可为零。
- 从结构化模型重新计算时域、连续谱、冲激线谱和分布项，不移动既有图形数据。
- 原始、变换后、同时显示三种图层模式，统一使用蓝色和橙色。
- 三张图使用包含两者的共同坐标范围。
- 动态展示原始/变换后时域公式、频域公式、变换性质与教学说明。
- 主值相位和展开相位切换，零幅值点仍保持未定义。
- 恢复原始信号与重置变换参数按钮。
- 提供可扩展操作队列接口，但 UI 优先保证单项变换。

## 第三阶段明确不包含

- 微分、积分及其页面操作。
- 多操作队列的可视化编辑器和复杂公式自动化简。
- 任意信号表达式输入。

## 第四阶段范围（已实现）

- 解析微分：`dx(t)/dt ↔ jωX(jω)`，普通导数、跳变冲激和冲激导数分别建模。
- 阶跃微分为 `δ(t)`；矩形微分为两个异号边缘冲激；单边指数微分包含 `Aδ(t)` 与普通指数项。
- 从负无穷累积积分：保留 `PV[X(jω)/(jω)] + πX(0)δ(ω)`，不以逐点除法替代分布运算。
- 支持冲激、平移冲激、矩形、三角、单/双边指数及 `te^{-at}u(t)` 的解析累积积分。
- UI 提供微分/积分选项、原始/变换后对比、分量摘要、PV 点外代表值和明确的相位适用说明。
- 对常数、阶跃、sinc 和周期信号等未实现或不收敛的积分返回明确原因，不生成伪结果。

## 第四阶段明确不包含

- 周期信号的零均值原函数模式与任意积分常数选择。
- 阶跃再次积分等需要更高阶广义函数乘积的情形。
- 多项变换的 UI 队列与复杂公式自动化简。

## 第五阶段最终保留范围（已按反馈精简）

- 页面聚焦基本信号、参数、五类变换、三张图和解析公式，不保留典型实验、独立教学推导及使用说明区域。
- 提供傅里叶变换性质速查、频率范围控制和响应式布局。
- 性质公式必须由本地 KaTeX 正确排版，不得出现 `longleftrightarrow`、`jomega` 或带反斜杠的原始 LaTeX 命令。
- 导出时域连续 CSV、频域连续 CSV、独立冲激谱 CSV和三张 PNG。
- 导出/导入带版本与数学约定标识的 JSON 页面配置。

## 第六阶段完成条件（已实现）

- 15个基本信号均有代表性时域和频域数值检查。
- 连续谱、冲激谱和PV等特殊分布分别验证，不通过浮点数组混淆。
- 翻转、平移、正负尺度、微分对全部信号类型执行性质验证；积分具有明确支持矩阵。
- 幅度与相位输出不得包含 NaN/Infinity；零幅值处相位保持未定义。
- `dist/index.html` 与全部资源使用相对本地路径，不进行运行时远程请求。
- 通过真实 Chrome/Edge `file://` 交互测试，覆盖参数、变换、公式渲染和导出。
- 生成离线目录和通用静态部署目录，并提供 GitHub Pages 部署步骤。
- README、架构、进度和测试报告与实际交付一致。
